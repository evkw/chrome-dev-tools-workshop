Useful Console Tools

Quick references for inspecting the page during a live demo.

$0
The currently selected element in the Elements panel.
$0.getBoundingClientRect()
Read the selected element's size and position.
getEventListeners($0)
Inspect listeners attached to the selected element.
monitorEvents($0, 'click')
Log click events occurring on the selected element.
unmonitorEvents($0)
Stop logging monitored events for the selected element.
console.table(...)
Display arrays or objects in a readable table.
Run and save browser diagnostics

DevTools → Sources → Snippets

In Sources, open the Snippets tab (under » if it is hidden), then choose New snippet, name it, and enter JavaScript. To find it from any DevTools panel, open the Command Menu with Ctrl / Cmd + Shift + P and choose Create new snippet or Show Snippets. Select a saved snippet and press Ctrl + Enter on Windows/Linux or Cmd + Enter on Mac to run it; the editor’s Run button also works.
