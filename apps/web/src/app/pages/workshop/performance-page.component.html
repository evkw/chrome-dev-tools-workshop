Record what the browser is doing

DevTools → Performance → Record

Start a recording, run the selected scenario, then stop and inspect the Main track. Long tasks point to JavaScript work; repeated Layout and Paint events reveal rendering costs.

Record→Reproduce→Inspect

Useful Performance checks

Main trackFind long tasks and see which work blocked input.

Call treeGroup recorded time by the functions that ran.

Bottom-upLocate the functions with the highest self time.

Layout eventsLook for repeated recalculation after DOM changes.

Paint eventsCheck how much visible content the browser repainted.

ScreenshotsRelate timeline activity to visible interface changes.
