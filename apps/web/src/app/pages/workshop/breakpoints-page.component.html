Create a logpoint for the running subtotal

In DevTools → Sources, open invoice-calculator.service.ts and set a logpoint on subtotal += line.baseAmount; with subtotal + line.baseAmount as the expression. Calculate the invoice to see the running total after each work item in the Console.
